# Optional New Tab wallpapers

These files use Firefox's native saved-wallpaper library format. None is
selected by default. They appear in the New Tab customization wallpaper picker
after being copied to `<profile>/wallpaper/library/`.

- `v1-custom-dark-center-1-c7de0001-2f4a-4c91-8a10-000000000001` — Blue Moon Statue
- `v1-custom-light-center-2-1c73f902-5e31-4c28-9b20-000000000002` — Green Dreamscape
- `v1-custom-light-center-3-a1b24103-7d62-4f39-ac30-000000000003` — Ivory Horizon

The theme includes optimized JPEG thumbnails so the picker can display all
three choices immediately.
