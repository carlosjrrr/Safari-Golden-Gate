# Changelog

All notable changes to Safari Golden Gate are documented in this file.

## 1.0.0 — 2026-10-14

The first public release of Safari Golden Gate.

### Highlights

- Compact, single-row navigation and tab layout.
- Reduced address bar with more room for visible tabs.
- Adaptive toolbar controls that reorganize when buttons are removed.
- macOS-inspired window controls aligned with the Firefox toolbar.
- Clear active-tab treatment, rounded tabs, and refined spacing.
- Consistent menus, context menus, pop-ups, and action buttons.
- Refined download, password, translation, Library, and Settings panels.
- Subtle icon animations with reduced-motion support.
- Liquid Glass styling for Firefox Home search, shortcuts, and widgets.
- Three optional wallpapers available through Firefox's native picker.

### Compatibility

- Firefox 158 or newer.
- Windows 10 and Windows 11.
- Firefox light theme only in this release.
